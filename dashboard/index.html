Risk tiers are capacity-aware, not a fixed probability cutoff: top ~10% of today's visits by predicted disruption risk are flagged High, next ~20% Medium — so the list stays reviewable in a coordinator's day rather than growing with the model's raw sensitivity. Predictions and reasons are model output (logistic regression on 6 features); recommended actions are rule-based, not yet AI-generated. This is one representative simulated day, not a cherry-picked best case — tier accuracy is directionally reliable in aggregate but noisy on any single day given current model strength.

Known limitation: the model currently over-indexes on first-time-patient status (it dominates most High-risk flags). New patients do disrupt more often in this data, but flagging them almost by default risks blanket extra scrutiny for a group where most individuals were never going to no-show. Before any production use, this would need feature rebalancing and a fairness review — not something to paper over with a better-looking demo. All data is simulated for portfolio purposes.
